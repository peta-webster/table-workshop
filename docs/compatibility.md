## 手动验证记录


- Chrome 浏览器实际操作：三种下载、样式切换、带 HTML 的复制、网页表格粘贴、错误输入与移动端宽度检查通过，无页面 JavaScript 错误。
- 独立读取 DOCX、XLSX、PPTX 检查原生表格、中文换行、空值、前导零、18 位编号、百分比和数值显示格式。
- 45 行中文表格分成 5 页 PPT，行序与内容完整，所有表格在幻灯片边界内。
- macOS Microsoft Word、Excel 和 PowerPoint 实际打开样例，中文与表格排版正常。
- LibreOffice 渲染检查使用任务目录内的字体配置；未更改系统或 Office 配置。
- WebMCP 的两个接口已在 Codex 内置浏览器中验证注册、有效输入、错误输入拒绝及状态保持。
- Word 粘贴修复：在 macOS Chrome 点击“复制表格”，通过系统剪贴板粘贴到 Word，选择“保留源格式”后，深蓝表头白字、中文与零首行缩进均保留。原来固定 680px 的表格越过右侧页面边界；改用百分比宽度后，左右页边距从 3.18cm 改为 5.08cm 时表格随之收缩。独立读取 Word 保存的 DOCX，确认表宽为 100%、表头文字颜色为 FFFFFF。
- Excel 无样式：在 macOS Chrome 实际复制，粘贴到预先设置格式的 Excel 区域并选择“匹配目标格式”。读取 Excel 保存的工作簿，确认 15 个单元格的内容、编号与 18 位数字文本、百分比数值、单元格换行、空值和公式样式文本正确；原 Arial 14 加粗、文字颜色、填充、边框、对齐、行高与列宽均保留。独立读取无样式导出 XLSX，确认没有装饰或额外标题行；界面切换验证 Excel 默认无样式、各目标样式独立保留、无效 WebMCP 组合不会修改状态。

尚未覆盖 Windows Office、所有浏览器、合并表格与复杂富文本。网页预览不是 Office 的逐像素渲染。
